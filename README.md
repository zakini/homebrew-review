# Zakini Review

## How do I install these formulae?

`brew install zakini/review/<formula>`

Or `brew tap zakini/review` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "zakini/review"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
